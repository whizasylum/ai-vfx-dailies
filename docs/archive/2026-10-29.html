GRESEARCH / 02IN THE DIGEST

GraftRay inserts physically lit, shadow-casting objects into Gaussian splat scenes

A new arXiv paper, GraftRay, proposes path-traced mesh insertion into 2D/3D Gaussian Splatting scenes with physically consistent lighting and shadows, addressing near-field lights like windows and lamps that environment-map approaches miss. It's research stage, no code or availability mentioned, but it targets the exact gap between splat reconstructions and usable VFX compositing: getting inserted CG objects to actually look lit by the scene.

WHY IT MATTERS

Points at the missing piece for using splat scans as real compositing plates.

Gemini Skills: Full Tutorial for Beginners + Free Skills

Transition of 'Gems' to 'Skills' for free Google accounts, introducing a standardized Markdown-based file format (SKILL.md) for defining custom AI behaviors, instructions, and triggers.

WHY IT MATTERS

While a consumer tool, the 'Skills' framework provides a clear template for managing system prompts. For a VFX TD, this structure is directly applicable when building internal tools that wrap LLMs for automated task descriptions, metadata tagging, or rapid concepting. The .md format makes it easy to version-control prompts.

  • Google Gemini
  • Gemini Skills
Inside the workflow · 3 takeaways
  • Structured system prompt architecture: dividing prompts into Name, Trigger (When), and Instructions (How).
  • Skill Stacking: a workflow for applying multiple specialized AI personas to a single prompt to refine output (e.g., combining a 'layout' skill with a 'render style' skill).
  • Iterative prompt refinement based on visual results, focusing on concrete descriptors like line weight, aspect ratio, and composition rules.
