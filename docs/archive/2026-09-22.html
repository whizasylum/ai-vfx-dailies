DNEG delivered 302 VFX shots for Motor City using concept-art projection onto period environments

DNEG was sole VFX vendor on Potsy Ponciroli's 1970s revenge thriller Motor City, delivering 302 shots across 15 sequences in 7 months. The studio projected VFX supervisor Serkan Selzele's own concept art directly onto period Detroit environments, tracked gore through a multi-stage elevator fight, and simulated a thermite shower for the climax. Released theatrically July 24.

WHY IT MATTERS

Concept-art-as-projection-texture is a workable technique worth understanding for fast turnaround period work.

AWORKFLOW / 04VIDEO REVIEW

GPT-6 Astra + After Effects Creates Motion Graphics in Minutes!

Integration of an agentic LLM (Astra) directly with the After Effects API, allowing users to describe complex motion tasks (physics, rigging, re-layouts) which are then executed as native, editable AE layers and keyframes.

WHY IT MATTERS

While AE-focused, the logic of using an agent with specific 'skills' (scripts/plugins) to handle boilerplate rigging and layout tasks is highly applicable to Houdini or Maya pipelines. A VFX TD could implement similar agentic patterns using the Houdini Python API to automate recurring setup tasks or variations.

  • Astra (GPT-agent)

Inside the workflow · 4 takeaways
  • Agentic DCC control: Using specialized LLM 'skills' to translate natural language into specific software API calls.
  • Automated ASCII conversion: Mapping brightness values of a source video to a grid of characters generated via an AI-authored script.
  • AI-driven physics simulation: Automating fall/rotate/bounce/settle keyframes for 2D layers without manual curve editing.
